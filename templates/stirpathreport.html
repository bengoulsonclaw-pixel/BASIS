Option table shows the nearest expiries (listed monthlies + 1Y quarterly midcurves); the full set lives on the terminal page. The overnight rate is modelled as a step function moving only on {{ meeting_name }} decision dates; in-arrears contracts settle to the daily-compounded index over their reference window (Euribor is priced as compounded-expected €STR plus a per-contract spread). The market-implied path is bootstrapped from the strip by smoothed least squares; per-meeting attribution within a window is indicative — read the cumulative path as the robust signal. “Mtgs before expiry” counts decisions an option lives through; “still open after” counts decisions inside its underlying's window after the option dies. Scenario figures are probability-weighted expected values under the stated meeting odds.
