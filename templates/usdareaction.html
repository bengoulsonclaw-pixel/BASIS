How to read it

{% if full %}Acreage above March intentions / year-ago = more new-crop supply = bearish; below = bullish. {% endif %}Stocks above year-ago = looser balance = bearish; below = tighter = bullish. On-farm heavy (on-farm rising faster than off-farm) = farmers holding grain — latent selling pressure to come. {% if dis %}Implied use up (prior-quarter minus this-quarter stocks vs a year ago) = stronger feed/residual demand = bullish.{% endif %} {% if not has_consensus %}
